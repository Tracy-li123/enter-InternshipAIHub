# 🎯 职达实习生 Chrome插件 - 快速使用指南

## ✅ 已完成的功能

插件已经可以**自动将采集的岗位数据发送到您的平台**！

---

## 🚀 使用流程

### 1️⃣ 配置平台地址

首次使用时需要配置：

1. 点击浏览器右上角的插件图标
2. 在弹窗底部找到"平台地址"输入框
3. 输入：`http://localhost:5173`（本地开发）
4. 地址会自动保存

### 2️⃣ 访问招聘网站

打开以下任意招聘网站的**岗位详情页**：

✅ **BOSS直聘** - https://www.zhipin.com/
- 搜索"实习生"
- 点击任意岗位进入详情页

✅ **拉勾网** - https://www.lagou.com/
- 搜索"实习"
- 点击任意岗位进入详情页

✅ **字节跳动** - https://jobs.bytedance.com/
- 找到实习岗位
- 点击进入详情页

✅ **腾讯招聘** - https://careers.tencent.com/

✅ **阿里巴巴** - https://talent.alibaba.com/

### 3️⃣ 采集岗位

**方式A：点击插件图标（推荐）**
1. 在岗位详情页，点击浏览器右上角的插件图标
2. 点击"🚀 采集当前岗位"按钮
3. 等待1-2秒

**方式B：使用浮动按钮**
1. 页面右下角会出现紫色的"📋 采集"按钮
2. 点击即可快速采集

### 4️⃣ 查看结果

采集成功后会显示：
```
✅ 成功导入《产品经理实习生》到平台
```

如果岗位已存在：
```
ℹ️ 《产品经理实习生》已存在于平台
```

### 5️⃣ 在平台查看

1. 点击插件弹窗中的"📱 打开职达实习生平台"
2. 或直接访问：http://localhost:5173
3. 在首页岗位列表中查看刚才采集的岗位

## ⚡ 技术原理

### 数据流转
```
招聘网站页面
    ↓ (采集)
Chrome插件
    ↓ (POST请求)
Supabase Edge Function
    ↓ (插入)
PostgreSQL数据库
    ↓ (查询)
职达实习生平台
```

### 智能去重
- 插件会检查相同标题+公司的岗位
- 如果已存在，不会重复插入
- 避免数据冗余

### 智能分类
- 自动根据岗位标题匹配分类
- 产品经理、数据分析、商业分析、产品运营

## 🐛 常见问题

### Q1: 点击"采集"后没有反应？
**A:** 请确保：
1. ✅ 你在岗位详情页（不是列表页）
2. ✅ 页面已完全加载（等待3-5秒）
3. ✅ 网站在支持列表中
4. ✅ 打开开发者工具（F12）查看是否有错误

### Q2: 显示"已保存到本地，但同步失败"？
**A:** 这说明：
1. 数据已保存在浏览器中（不会丢失）
2. 但无法连接到后端API
3. 可能原因：
   - 平台地址配置错误
   - 本地服务未启动（需要运行 `npm run dev`）
   - 网络问题

**解决方法：**
1. 确保平台正在运行（访问 http://localhost:5173 能打开）
2. 检查插件中的"平台地址"是否正确
3. 重新点击"采集"按钮

### Q3: 如何查看本地保存的数据？
**A:** 
1. 右键点击插件图标
2. 选择"检查弹出内容"
3. 在Console中输入：
```javascript
chrome.storage.local.get(['savedJobs'], (result) => {
  console.log(result.savedJobs);
});
```

### Q4: 插件能在无痕模式使用吗？
**A:** 可以，但需要：
1. 进入 chrome://extensions/
2. 找到"职达实习生"插件
3. 点击"详情"
4. 勾选"在无痕模式下启用"

### Q5: 数据安全吗？
**A:** 
- ✅ 插件只在你主动点击时采集信息
- ✅ 数据直接发送到你自己的数据库
- ✅ 不会发送到任何第三方服务器
- ✅ 符合隐私保护原则

## 🔧 开发者选项

### 查看插件日志

**Popup日志：**
1. 右键插件图标 → 检查弹出内容
2. 查看Console标签

**Content Script日志：**
1. 在招聘网站页面按F12
2. 查看Console标签
3. 过滤："职达实习生"

**Background Service日志：**
1. 访问 chrome://serviceworker-internals/
2. 找到"职达实习生"
3. 点击"inspect"

### 调试API调用

在插件Popup的Console中：
```javascript
// 查看最后一次采集的数据
chrome.storage.local.get(['lastJob'], console.log);

// 查看平台地址配置
chrome.storage.sync.get(['platformUrl'], console.log);

// 清空本地缓存
chrome.storage.local.clear();
```
