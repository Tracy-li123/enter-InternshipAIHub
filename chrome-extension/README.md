# 职达实习生 - Chrome扩展插件

## 📦 安装方法

### 方法一：开发者模式安装（推荐）

1. **打开Chrome扩展管理页面**
   - 在Chrome浏览器地址栏输入：`chrome://extensions/`
   - 或者：菜单 → 更多工具 → 扩展程序

2. **启用开发者模式**
   - 点击页面右上角的"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择 `chrome-extension` 文件夹
   - 点击"选择文件夹"

4. **完成！**
   - 扩展图标会出现在浏览器右上角
   - 如果没有显示，点击拼图图标，找到"职达实习生"并固定

## 🎯 使用方法

### 1. 访问招聘网站
打开以下任意招聘网站的岗位详情页：
- BOSS直聘：https://www.zhipin.com/
- 拉勾网：https://www.lagou.com/
- 字节跳动：https://jobs.bytedance.com/
- 腾讯招聘：https://careers.tencent.com/
- 阿里巴巴：https://talent.alibaba.com/

### 2. 采集岗位信息

**方式A：点击插件图标**
1. 在岗位详情页，点击浏览器右上角的插件图标
2. 点击"🚀 采集当前岗位"按钮
3. 等待采集完成

**方式B：使用浮动按钮**
1. 页面右下角会出现"📋 采集"浮动按钮
2. 点击即可快速采集

### 3. 查看采集结果
- 采集成功后会显示提示信息
- 数据会自动保存到本地
- 点击"📱 打开职达实习生平台"查看所有采集的岗位

## ⚙️ 配置

### 自定义平台地址（重要！）

1. 点击插件图标打开弹窗
2. 在底部"平台地址"输入框中输入你的平台地址

**本地开发环境：**
```
http://localhost:5173
```

**生产环境（部署后）：**
```
https://your-domain.com
```

> **注意**：插件会自动根据平台地址调用对应的API接口

## 🛠 开发

### 目录结构
```
chrome-extension/
├── manifest.json       # 插件配置文件
├── popup.html         # 弹窗页面
├── popup.js          # 弹窗逻辑
├── content.js        # 页面注入脚本
├── background.js     # 后台服务
├── icon16.png        # 图标 16x16
├── icon48.png        # 图标 48x48
├── icon128.png       # 图标 128x128
└── README.md         # 说明文档
```

### 调试
1. 修改代码后，在扩展管理页面点击"重新加载"
2. 查看控制台日志：
   - 右键插件图标 → 检查弹出内容（popup日志）
   - F12开发者工具 → Console（content script日志）
   - chrome://serviceworker-internals/（background日志）

## 📝 注意事项

1. **需要图标**
   - 请准备三个尺寸的图标：16x16、48x48、128x128
   - 格式：PNG
   - 放在 `chrome-extension/` 文件夹中

2. **隐私安全**
   - 插件仅在你主动点击时采集信息
   - 所有数据存储在本地
   - 不会自动上传到任何服务器

3. **网站更新**
   - 如果招聘网站更新了页面结构，插件可能需要更新
   - 请及时反馈问题

## 🐛 常见问题

### Q: 插件无法采集信息？
A: 请确保：
- 你在岗位详情页（不是列表页）
- 页面已完全加载
- 网站在支持列表中

### Q: 如何查看采集的数据？
A: 打开开发者工具（F12）→ Application → Storage → Local Storage → 查看 `savedJobs`

### Q: 数据如何同步到平台？
A: 目前数据保存在本地，需要手动导入到平台。未来版本会支持自动同步。
